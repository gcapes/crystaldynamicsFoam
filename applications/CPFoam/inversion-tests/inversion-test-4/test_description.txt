INVERSION TEST 4 — Intentionally non-symmetric input tensor
============================================================

PURPOSE
-------
Tests the symmetry enforcement and warning pipeline with a deliberately
non-symmetric stiffness tensor entered in GrainProperties. Symmetric pairs
(e.g. C0011 and C1100) are assigned different values.

This test confirms:
  - WarningInFunction fires at initialisation for each asymmetric component group.
  - castSymmetry correctly averages the non-symmetric pairs before the solve.
  - assertSymmetry PASSES on the symmetrised result (no FatalError at init).
  - fourthToMandel safety checks never fire during the solve.
  - The inversion produces a physically meaningful compliance tensor.

NOTE: The user is responsible for ensuring their input tensor is physically
meaningful. castSymmetry will symmetrise any input, but the result is only
physically correct if the asymmetry was unintentional (e.g. a typo). If
the input is genuinely non-symmetric there is no unique "correct" inversion.

Must be used with verbose option for inversion functionality.

INPUT TENSOR (intentionally asymmetric pairs)
---------------------------------------------
  C0000 = 1.40e11,  C1111 = 1.40e11,  C2222 = 1.40e11

  C0011 = 9.20e10   but   C1100 = 8.50e10   (major symmetry violated, delta=7e9)
  C0022 = 9.20e10   but   C2200 = 8.80e10   (major symmetry violated, delta=4e9)
  C1122 = 9.20e10   but   C2211 = 9.00e10   (major symmetry violated, delta=2e9)

  C0101 = 1.11e11   but   C0110 = 1.00e11   (minor symmetry violated, delta=1.1e10)
  C0202 = 1.11e11   but   C0220 = 1.05e11   (minor symmetry violated, delta=6e9)
  C1212 = 1.11e11   but   C1221 = 1.08e11   (minor symmetry violated, delta=3e9)

  All other components set symmetrically.
  Crystal orientation: phi1=0.26, phi2=0, phi3=0

EXPECTED OUTPUT
---------------
  At initialisation:
    WarningInFunction fired for each asymmetric group (6 warnings expected).
    assertSymmetry passes without FatalError.

  During solve — fourthToMandel symmetry diagnostics (all calls):
    max |C(i,j,k,l) - C(j,i,k,l)| = 0
    max |C(i,j,k,l) - C(i,j,l,k)| = 0
    max |C(i,j,k,l) - C(k,l,i,j)| = 0

  Symmetrised values (averages of asymmetric pairs, approximate):
    C0011_sym ~ 8.85e10  Pa   (average of 9.20e10 and 8.50e10)
    C0101_sym ~ 1.055e11 Pa   (average of 1.11e11 and 1.00e11)

  Compliance diagonal (Mandel, approximate, symmetrised cubic):
    S_M(0,0) = S_M(1,1) = S_M(2,2) ~ 1.1e-11  Pa^-1
    S_M(3,3) = S_M(4,4) = S_M(5,5) ~ 9.5e-12  Pa^-1
    (slightly different from test-2 due to averaged-down stiffness)
