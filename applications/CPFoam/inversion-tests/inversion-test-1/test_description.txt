INVERSION TEST 1 — Cubic FCC, C_max ~ 1e10, non-trivial rotation
==================================================================

PURPOSE
-------
Reproduces Tom's original error case (10/03/2026). The stiffness tensor is for a
cubic FCC material (Fe-35Ni) with components of order 1e10 Pa. The crystal
orientation is phi1 = 0.26 rad, which applies a non-trivial rotation to the
tensor every constitutive step. Must be used with verbose option for inversion functionality.

This test confirms:
  - The rotation-induced floating-point symmetry noise (~1e-6 for C_max~1e10)
    is eliminated by the Mandel-pair castSymmetry fix.
  - fourthToMandel symmetry diagnostics report exactly 0 for all residuals.
  - No FatalError is thrown.
  - The inversion pipeline completes for every cell every timestep.

INPUT TENSOR (unrotated, Material.0)
-------------------------------------
  C11 = C22 = C33 = 1.40e10  Pa   (C0000, C1111, C2222)
  C12 = C13 = C23 = 9.20e9   Pa   (C0011, C0022, C1122 and symmetric pairs)
  C44 = C55 = C66 = 1.11e10  Pa   (shear: C0101, C0202, C1212 and symmetric pairs)

  Crystal orientation: phi1=0.26, phi2=0, phi3=0  (Bunge Euler angles)

EXPECTED OUTPUT
---------------
  fourthToMandel symmetry diagnostics (all calls):
    max |C(i,j,k,l) - C(j,i,k,l)| = 0
    max |C(i,j,k,l) - C(i,j,l,k)| = 0
    max |C(i,j,k,l) - C(k,l,i,j)| = 0

  Compliance diagonal (Mandel, unrotated frame, approximate):
    S_M(0,0) = S_M(1,1) = S_M(2,2) ~ 1.1e-10  Pa^-1
    S_M(3,3) = S_M(4,4) = S_M(5,5) ~ 9.0e-11  Pa^-1

  C_rot : C_rot_inv = I4  (verified by isRankFourInverse if called)

  Run crashed with FPE in constitutive pow() at t~4.6e-9s — unrelated to
  inversion, pre-existing instability in slip rate at high k_exponent=500.
